# План разработки расширения «SERP Analyzer» под Яндекс

## 1. Цели и сценарии
**Цель:** быстро собирать и визуализировать ключевые метрики выдачи Яндекса по запросу.  
**Основные сценарии:**
- SEO‑специалист вводит запрос → расширение анализирует текущую страницу выдачи Яндекса.
- Получает сводку: длина Title/Description (сниппет), типы страниц, доменные зоны, наличие расширенных сниппетов.
- Экспортирует данные в CSV или копирует в буфер.

---

## 2. Функциональные требования (MVP)

### 2.1. Анализ SERP Яндекса
- Парсинг органических результатов:
  - Title, Description (сниппет), URL, домен.
  - Длина Title/Description (в символах).
  - Частотность ключевых слов в заголовках.
- Детекция расширенных сниппетов:
  - Картинки, быстрые ссылки, ответы, FAQ.

### 2.2. UI и взаимодействие
- Кнопка в тулбаре → панель справа (side panel).
- Таблица результатов + сводные метрики.
- Фильтры:
  - длина Title/Description,
  - доменная зона (.ru, .com, .org),
  - наличие расширенных сниппетов.

### 2.3. Экспорт
- Экспорт CSV.
- Копирование таблицы в буфер.

---

## 3. Архитектура расширения

### 3.1. Manifest V3
**Permissions:**
- `activeTab`
- `scripting`
- `storage`

**Основные компоненты:**
- **Content script** — парсит DOM выдачи Яндекса.
- **Service worker** — обработка, хранение и экспорт данных.
- **Side panel UI** — отображение таблицы и метрик.

### 3.2. Поток данных
1. Content script парсит выдачу.
2. Отправка данных в service worker.
3. Service worker обрабатывает результаты.
4. UI показывает таблицу и сводку.

---

## 4. Этапы разработки

### Этап 1 — каркас
- Создать manifest, background/service worker, content script, UI.
- Поднять side panel.

### Этап 2 — парсинг Яндекс SERP
- Определить основные DOM‑селекторы органики.
- Протестировать устойчивость селекторов.

### Этап 3 — базовый UI
- Таблица результатов.
- Метрики: средняя длина Title/Description, топ‑слова.

### Этап 4 — экспорт
- CSV экспорт.
- Копирование результатов.

### Этап 5 — улучшения
- Фильтры.
- Детекция расширенных сниппетов.
- Классификация типов страниц (лендинг/каталог/статья).

---

## 5. Риски и ограничения
- Яндекс часто меняет структуру DOM → нужна стратегия fallback (несколько селекторов).
- Ограничение CORS при попытке доп. запросов (в MVP избегать).
