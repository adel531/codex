# Yandex SERP Analyzer (Chrome Extension)

## Что делает
- Анализирует органическую выдачу Яндекса на текущей странице.
- Показывает ключевые метрики (длины title/сниппетов, доменные зоны, типы сниппетов).
- Экспортирует результаты в CSV или копирует таблицу в буфер.

## Как запустить локально
1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Load unpacked** и выберите папку репозитория.
4. Перейдите на страницу выдачи Яндекса и нажмите на иконку расширения.

## Структура проекта
- `manifest.json` — описание расширения (Manifest V3).
- `background.js` — service worker, хранение результатов.
- `content.js` — парсинг выдачи Яндекса.
- `sidepanel.*` — UI боковой панели.
